# QuakeLens Japan

**建物の築年分布（Project PLATEAU）× 地震ハザード・表層地盤（J-SHIS）× AI防災解説（Gemini API Function Calling）**

Google AI Challenge 2026 応募作品として開発された、公的オープンデータに基づく防災情報の可視化・地域分析・自然言語解説Webアプリケーションです。

> [!IMPORTANT]
> 本ツールは個別建物の耐震診断や倒壊確率の予測を行うものではありません。公開データ（Project PLATEAU・J-SHIS・気象庁）に基づく防災情報の可視化・分析支援ツールです。

---

## 1. 対象自治体の選定理由と属性取得率

### 選定地域：**京都府京都市全域（11区）**

当初は東京23区を第一候補として、国土交通省 Project PLATEAU（[G空間情報センター CKAN](https://www.geospatial.jp/ckan/)）の `plateau-tokyo23ku-citygml-2020` および `plateau-tokyo23ku-2022` のCityGMLファイルを直接検証しました。その結果、東京23区データでは標準の建築年属性（`bldg:yearOfConstruction`）が **0%**（未整備）であることが判明しました。

そこで、全国主要自治体のPLATEAUデータを横並びで調査した結果、以下の理由から **京都市（2025年度版：`plateau-26100-kyoto-shi-2025`）** を対象地域として選定しました。

1. **最新の標準仕様・高い属性網羅率**
   - 2025年度整備・2026年5月更新（標準製品仕様書第5.0版）
   - 総建物数：**513,815棟**（242メッシュファイル全件処理）
   - 建築年判明率：**80.9%**（415,456棟が判明 / **98,359棟・19.1%が不明**）
   - 建物用途判明率：**82.3%**
   - 建物構造判明率：**79.1%**
   - 地上階数判明率：**80.0%**
2. **建築年区分のバランスの良さと欠損値の存在**
   - 1981年以前：**158,446棟**
   - 1982〜2000年：**131,749棟**
   - 2001年以降：**125,261棟**
   - 建築年不明：**98,359棟**（推測や補完を一切行わず「不明」として保持）
3. **市内の地震ハザード・表層地盤のコントラスト**
   - 東山区などの砂礫質台地では30年震度6弱以上確率（`T30_I55_PS`）が約5%前後である一方、伏見区・山科区などの後背湿地では50%を超えるメッシュが存在し、建物築年数と地盤・ハザードの重なりを直感的に分析できます。

## 2. 主な機能

1. **インタラクティブ地図（MapLibre GL JS + 地理院タイル）**
   - 築年区分による建物ポリゴンの色分け（1981年以前 / 1982〜2000年 / 2001年以降 / 建築年不明）
   - 色覚多様性（Okabe-Ito）に配慮した建物カラーパレットと紫系ハザードメッシュの明確な視覚分離
   - J-SHIS 250mメッシュオーバーレイ（「今後30年震度6弱以上確率」と「表層地盤最大速度増幅率 ARV」を切替可能）
   - 気象庁 地震発生履歴（震源・M・最大震度）のオーバーレイ表示
   - 築年区分・ハザード区分・用途区分・行政区（11区）による即時フィルタリング
2. **統計ダッシュボード（Recharts）**
   - 対象棟数・建築年判明率・建築年不明件数（分母と欠損を明示）
   - 「築年区分別棟数」「地震ハザード区分 × 築年区分」のインタラクティブグラフ（棒グラフクリックで地図フィルター連動）
3. **優先確認エリア分析（250mメッシュ単位）**
   - 統一座標系（`EPSG:6674`：JGD2011 平面直角座標系第VI系）での空間結合により、250mメッシュごとに総棟数・建築年判明率・1981年以前棟数・震度6弱以上確率・ARV・微地形区分を集計
   - 任意の重み付け危険度スコアを使わず、実測値ベースのソートで優先確認エリアを一覧表示（クリックで該当メッシュへ自動ズーム）
4. **詳細インスペクター＆公式耐震補助案内**
   - 建物・250mメッシュをクリックして建築年・構造・用途・地盤・ハザード確率を確認
   - 京都市公式の無料耐震診断（「木造住宅及び京町家の耐震診断士派遣事業」）および改修補助（「まちの匠・ぷらす」）等の確認済み公式ページへの導線を表示
5. **Gemini AI 防災解説アシスタント（Function Calling）**
   - `google-genai` SDK（`gemini-4-hydrogen` / Interactions API）を利用
   - バックエンドの実データ照会ツール（`get_area_statistics`, `get_priority_confirmation_areas`, `get_mesh_details`, `get_building_details`, `get_data_methodology_and_programs`）をFunction Callingで呼び出し、実測値に基づいた解説を生成
   - 回答カード下に「参照ツール（Function Calling）」バッジを表示し、数値の根拠を透明化

## 4. データの扱いに関する重要な前提・制約

- **ハザード確率の定義**：`T30_I55_PS`（今後30年間に震度6弱以上の揺れに見舞われる確率）等は地震動の発生確率であり、**個別建物の倒壊確率やリアルタイム地震予知ではありません**。
- **建築年の粒度と耐震基準**：PLATEAUの `bldg:yearOfConstruction` は「年」単位のデータです。1981年6月1日施行の新耐震基準や、2000年6月1日施行の木造住宅に関する基準（接合部・耐力壁バランス等）は「月日」に依存するため、築年数のみで厳密に適合・不適合を判定していません。
- **欠損値の扱い**：建築年が未入力または異常値（`0001`・`9999`等）の建物は推測せず「建築年不明」として集計・表示しています。用途が `461`（不明）または欠損の建物も勝手に住宅扱いしていません。

## 5. セットアップ・起動方法（Mac / Linux）

前処理済みの京都市データ（`backend/data/processed/buildings.parquet`, `meshes.geojson`, `summary.json`）を同梱しているため、**APIキーなしでも地図・フィルター・統計・優先エリア分析がそのまま動作します**。AI防災解説機能を利用する場合のみ `.env` に `GEMINI_API_KEY` を設定してください。

> [!NOTE]
> 本アプリは **2つのサーバー** で構成されています。
> - **Webアプリ画面（ブラウザで開くURL）**: `http://localhost:3000`（Next.js フロントエンド）
> - **APIサーバー**: `http://127.0.0.1:8000`（FastAPI バックエンド／API仕様: `http://127.0.0.1:8000/docs`）
>
> バックエンドだけを起動して `http://127.0.0.1:8000` を開くと案内ページが表示されます。地図とダッシュボードを表示するには **フロントエンドも起動して `http://localhost:3000` にアクセスしてください。**

### 必要環境
- Python 3.12+ & `uv`
- Node.js 20+ & `npm`

### 1) 環境変数設定（任意：AI解説を使う場合）

```bash
cp .env.example .env
# .env を開き、GEMINI_API_KEY=あなたのAPIキー を記入
```

### 2) かんたん一括起動（推奨）

リポジトリルートで `./start.sh` を実行すると、バックエンド（`:8000`）とフロントエンド（`:3000`）を同時に起動します：

```bash
./start.sh
```

起動後、ブラウザで **`http://localhost:3000`** を開いてください（終了は `Ctrl + C`）。

### 3) 個別に起動する場合（2ターミナル）

**ターミナル1：バックエンド起動（FastAPI: `http://127.0.0.1:8000`）**

```bash
cd backend
uv sync
uv run uvicorn app.main:app --host 127.0.0.1 --port 8000
```

> データパイプラインをゼロから再実行して最新データを取得・再構築する場合：
> ```bash
> cd backend
> uv run python scripts/fetch_and_build.py
> ```

**ターミナル2：フロントエンド起動（Next.js: `http://localhost:3000`）**

```bash
cd frontend
npm install
npm run dev
# 本番ビルドで起動する場合: npm run build && npm run start -- --port 3000
```

起動後、ブラウザで **`http://localhost:3000`** を開きます。

## 6. アプリの正しい使い方

1. **全体俯瞰（初期表示）**：京都市全域の250m地震ハザードメッシュ（今後30年震度6弱以上確率）と、右パネルの築年区分別・ハザード区分別の統計グラフを確認します。
2. **レイヤー・地域切り替え（左パネル）**：
   - 行政区（11区）を切り替えると、地図が該当区へ移動し統計・優先確認エリアも連動更新されます。
   - 250mメッシュは「震度6弱+確率」と「表層地盤増幅率（ARV）」をワンクリックで切り替えられます。
   - 「気象庁 直近震源履歴」をONにすると、直近の震源円が地図上に重なります。
3. **個別建物の確認（ズームイン）**：
   - 地図をズームイン（ズームレベル `14.2` 以上）するか、250mメッシュをクリックすると、PLATEAUの個別建物ポリゴンが築年区分（1981年以前 / 1982〜2000年 / 2001年以降 / 不明）で色分け表示されます。
   - 建物やメッシュをクリックすると右側の「詳細・補助」タブに建築年・構造・用途・地盤・ハザード確率・京都市公式の耐震診断/補助制度リンクが表示されます。
4. **優先確認エリアの抽出（右パネル「統計・エリア」タブ下部）**：
   - 「高ハザード×1981以前順」「1981以前棟数順」「震度6弱+確率順」等で250mメッシュを並び替え、行をクリックすると該当エリアへ直接ズームインします。
5. **AI防災解説（右パネル「AI防災解説」タブ）**：
   - `.env` に `GEMINI_API_KEY` を設定している場合、質問例チップまたは自由入力で質問すると、Geminiがバックエンドの実測データツール（Function Calling）を呼び出して根拠付きで回答します。

## 8. Google AI Challenge 2026 提出用 90秒デモ構成案

- **0:00〜0:15｜課題提起**：日本には1981年以前の建物が多く残る一方、建物情報（PLATEAU）と地震ハザード（J-SHIS）は別々に公開されている。両者を統合し、一般市民が地域の防災特徴を直感的に理解できる「QuakeLens Japan」を紹介。
- **0:15〜0:35｜全体俯瞰とコントラスト（京都市全域）**：250mメッシュを表示し、東山区等の台地（震度6弱+確率約5%）と伏見区・山科区等の後背湿地（50%超・ARV 2.0+）の明確な違いを地図とグラフで提示。上部のKPIで「513,815棟・建築年判明率80.9%・不明19.1%」という分母の透明性を強調。
- **0:35〜0:55｜優先確認エリア抽出と個別建物インスペクション**：右パネルの「優先確認エリア」トップ（例：山科区メッシュ `5235367414`）をクリックして即座にズームイン。1981年以前の木造建築群（オレンジ色）と高ハザード地盤の重なりを地図上で確認し、建物をクリックして建築年・構造・京都市の公式耐震診断/補助制度リンクを表示。
- **0:55〜1:20｜Gemini AI（Function Calling）による実データ解説**：AIタブで「1981年以前の建物が多い優先確認エリアを教えて」「この地図の数値は何を意味していますか？」を質問。Geminiが裏側の実データツールを呼び出して正確な棟数・確率を根拠付きで解説し、倒壊確率ではない注意点と公式制度まで案内する様子を実演。
- **1:20〜1:30｜まとめ**：公的オープンデータ × 空間結合 × Gemini Function Calling による、ハルシネーションを抑えた再現可能な地域防災インテリジェンスとして締めくくる。
